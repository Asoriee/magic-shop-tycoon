## 3. Экономия токенов (Token Economy)
1. **Точечное чтение**:
   - Запрещено читать файлы целиком (`view_file` без параметров или >100 строк).
   - Всегда находить нужный блок через `grep_search` или `Select-String`, затем читать диапазон `StartLine`/`EndLine` (не более 40–80 строк).
2. **Хирургические правки**:
   - Использовать `replace_file_content` с минимальными уникальными блоками контекста (3–8 строк до/после). Запрещены масштабные перезаписи всего файла.
3. **Фильтрация вывода команд**:
   - Ограничивать вывод консоли (`Select-String`, `| Select-Object -First 20`, `head`, `tail`). Не выводить сырые мегабайты логов.
4. **Запрет поллинга**:
   - Запрещены циклы ожидания фоновых задач через `manage_task(status)`. Система сама отправляет системное уведомление при завершении процесса.
5. **Сжатие данных (Headroom)**:
   - При обработке длинных логов, дампов состояний и диагностических данных использовать MCP-инструмент `headroom_compress`.

## 5. Правила разработки и вёрстки
- **CSS-каскад**: Базовые стили компонентов ВСЕГДА объявляются ДО блоков `@media`. Блоки `@media (max-width: ...)` располагаются строго в конце `<style>`, иначе специфичность базовых правил ломает адаптивность.
- **Flex-контейнеры со скроллом**: Секции внутри вертикальных скролл-областей (`overflow-y: auto`) обязаны иметь `flex-shrink: 0;`. Запрещено использовать `overflow-x: hidden` внутри вложенных секций (вызывает нежелательный `overflow-y: auto`).
- **Мобильный вьюпорт**: `:global(html, body) { overflow-x: hidden; max-width: 100vw; }` обязателен для предотвращения горизонтального дрейфа от SVG/анимаций.
- **Оптимизация 60 FPS**: Анимации — строго через аппаратный CSS Compositor (`transform: translate3d`, `opacity`, `will-change`). Запрещен SMIL `<animate>` в циклах и тяжелые SVG-фильтры `feGaussianBlur` на мобильных.
