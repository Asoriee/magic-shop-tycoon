# Дневник проекта: Магический магазин (Magic Shop Tycoon)

> Документ обновляется в ходе разработки. Фиксирует ключевые решения, архитектуру, состояние механик и приоритеты оптимизации.

---

## 1. Стек и фундаментальные правила
- **Платформа**: Яндекс Игры (Yandex SDK v2).
- **Стек**: Svelte + TypeScript + Vite + GSAP.
- **Графика**: Строго 100% чистый SVG (никаких растровых картинок и сторонних шрифтов).
- **Платформы**: Мгновенная адаптивность под десктоп и мобильные устройства.
- **Локализация**: Полный перевод на 3 ключевых языка комьюнити (Русский, Английский, Турецкий).
- **Звук**: Web Audio API (синтез процедурных звуковых эффектов на осцилляторах без внешних mp3).
- **Ограничения агента**: Строго запрещен `browser_subagent`. Визуальная проверка — Chrome headless через PowerShell.

---

## 2. Ключевые системы и механики
- **Котел**: Клик/тап, термодинамика перегрева (Heat gauge & Combo multiplier), тактильный GSAP squash & stretch.
- **Экономика**: Золото, Кристаллы, Звездная пыль (Stardust), 15+ рецептов алхимии, ингредиенты 4 редкостей.
- **Прогресс**: Ребирты (Перерождения) с древом талантов за звездную пыль.
- **Питомцы**: 6 уникальных спутников с пассивными аурами, прокачкой уровней и экспедициями.
- **Монетизация**:
  - Банк (Стартер пак, наборы кристаллов за Яны через Yandex Payments SDK).
  - Бесплатный ежедневный подарок в банке.
  - Rewarded Video (Дар летящей искры, пропуск таймеров, умножение офлайн-дохода).
  - Календарь наград: 7-дневный цикл с недельными вехами.
  - Interstitial реклама при закрытии модалок с тайм-аутом антиспама.

## 3. Выполненные этапы (Хронология)
1. **Redesign Starter Pack & Bank Modal**: Премиальное золото/рубиновое оформление, таймер выгоды x4, бейджи бестселлеров (`822dda9`).
2. **Mobile Touch Targets**: Увеличение всех зон клика (close buttons, bottom dock, icon buttons) до строгих >=44x44px (`a323342`).
3. **Daily Calendar Overhaul**: 7-дневный непрерывный цикл, полоса недельного прогресса, гарантированный сундук 7-го дня (`a31600b`).
4. **Haptic & Tactile Juice**: Эластичные отскоки котла, импульсы прокачки в магазине, вибро-шейк при нехватке золота (`9e535d4`).
5. **Yandex Build & Security**: Zero-404 бандл `magic-shop-tycoon-yandex.zip`, валидация времени сервера против манипуляций часами, защита от автокликеров (ClickRateLimiter).
6. **Mobile 60 FPS Engine Overhaul**:
   - `ParallaxBackground.svelte`: замена `feGaussianBlur` на аппаратные радиальные градиенты GPU; перенос всплывающих пузырей с 24-64 JS-тикеров GSAP на чистый CSS Compositor (`translate3d`).
   - `Cauldron.svelte`: ликвидация 15 SMIL `<animate>` тегов; переход на аппаратные CSS-кейфреймы пузырей; оптимизация вылетающих цифр через `-webkit-text-stroke` вместо 40 проходов `text-shadow`.
   - `PetCompanion.svelte`: удаление невалидного фильтра размытия, внедрение шейдерной ауры и аппаратного покачивания/дыхания без JS-нагрузки.
   - `FlyingBonus.svelte`: удаление двойной фильтрации на летящей сущности.
   - `App.svelte`: отключение `backdrop-filter` на плавающих баффах на мобильных экранах.
   - Результат: 0ms фонового JS-тика на анимациях, разгрузка потока отрисовки, стабильные 60 FPS.
7. **Harmonized Arcanum Modal Mobile Opening**:
   - Окно «Арканум» (`PremiumModal.svelte`) переведено на единый мобильный стандарт (`@media (max-width: 680px)`): полноэкранный режим `100dvh`, нулевые отступы оверлея, отключение размытия подложки, синхронизированный `z-index: 1000`. Полное единообразие со всеми модальными окнами главного хаба (`545b78a`).
8. **GameplayAPI Event Deduplication**:
   - В `src/yandex-sdk.ts` внедрен внутренний трекинг активности геймплея `isGameplayActive`. Исключены избыточные postMessage-сообщения `gameplay_api_start` при частых кликах и переключениях фокуса окна; консоль и связь с контейнером Яндекса очищены от спама событий.
9. **Mobile Chest Loot Grid Responsive Overhaul**:
   - В `ChestShopModal.svelte` исправлена фаза выдачи наград (`phase === 'loot'`):
     * Брейкпоинт синхронизирован с остальными модалками (`@media (max-width: 680px)`).
     * Обнулены внешние отступы подложки `.overlay` и `.cinematic-overlay` (устранено 80px лишних невидимых отступов).
     * Сетка наград `.loot-grid` переведена на `repeat(3, minmax(0, 1fr))` со строгим `box-sizing: border-box`, `min-width: 0`, `overflow: hidden` у карточек — 3 колонки идеально помещаются в ширину любого мобильного экрана без горизонтального срезания.
     * Для ультра-узких экранов (<=340px) предусмотрен адаптивный фоллбэк в 2 колонки.
     * Кнопка «Забрать в инвентарь» закреплена внизу (`position: sticky`), доступна без обязательного скролла длинного списка.
10. **Mobile Daily Quests Tab Responsive Overhaul**:
   - В `DailyQuestsModal.svelte` устранена проблема сильного сжатия и обрезки текста заданий на мобильных экранах (`@media (max-width: 680px)`):
     * Карточка квеста `.quest-card` перестроена с плоской 1-строчной структуры (где 5 элементов сжимали название задачи до 3-4 букв) на эргономичную двухстрочную компоновку:
       1. Верхняя строка: иконка (40px/34px), бейдж сложности (`легкий`/`средний`/`сложный`), полное переносимое название задания (`word-break: break-word; flex-wrap: wrap`) и компактная плашка награды (золото/кристаллы).
       2. Нижняя строка: вытянутый прогресс-бар с моноширинным счетчиком `X / Y` и кнопка сбора / статус выполнения.
     * Сохранены все Svelte-биндинги `bind:this` для GSAP-анимаций прогресса и интерактивности кнопок сбора.
     * Добавлены адаптивные стили для баннера гильдии, карточки «Ларец Мастера Дня» и фоллбэки для ультра-узких экранов (<=380px).
