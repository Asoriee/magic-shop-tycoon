## 4. Параметры публикации и модерации

- **Ориентация \***: `Любая` (адаптивный интерфейс под вертикальные экраны телефонов и горизонтальные ПК)
- **Возрастной рейтинг \***: `0+` (в игре отсутствует жестокость, нецензурная лексика и азартные игры)
- **Категории \***:
  1. `Казуальные`
  2. `Симуляторы` (или `Для детей`)
- **Теги**: `Кликеры`, `Тайкуны`, `Симуляторы`, `Магия`, `Зельеварение`, `Питомцы`, `Прокачка`, `Для мальчиков`, `Для девочек`
- **Ключевые слова (92 / 100 символов)**:
  `магический магазин, кликер, тайкун, алхимия, зелья, симулятор, питомцы, магия, idle, драконы`
- **Игра использует облачные сохранения**: `ВКЛЮЧЕНО` (активен, игра интегрирована с `ysdk.getPlayer().setData()`)
- **Отсроченная публикация**: `ВЫКЛЮЧЕНО` (публиковать сразу после успешной модерации)

### Комментарий разработчика:
```text
Здравствуйте, уважаемая команда модерации Яндекс Игр!

Игра «Магический магазин» — казуальный симулятор-тайкун с зельеварением, экспедициями питомцев, лавкой артефактов и сезонным календарем.

Информация для проверки (SDK v2 и регламент):

1. Авторизация и сохранения (п. 1.2, 1.9):
- Гостевой вход (mode: 'lite'): игра доступна сразу без обязательного логина.
- Прогресс сохраняется в localStorage и в облаке Яндекс Игр (ysdk.getPlayer().setData()). При авторизации гостя прогресс бесшовно переносится в облако.
- Авторизация предлагается исключительно по клику на кнопку «Войти» в окне лидерборда с описанием преимуществ.

2. Звук и системный плеер (п. 1.3, 1.6):
- Звуки синтезируются через Web Audio API (тегов <audio> нет, системный плеер в браузере и шторке уведомлений не вызывается).
- При сворачивании окна, потере фокуса (visibilitychange, blur) и во время рекламы звук останавливается.

3. Инап-покупки и реклама (п. 1.12, 1.13, 4.4):
- Консумирование настроено: на старте вызывается checkPurchases() для обработки незавершенных платежей.
- Цены и коды валют динамически берутся из каталога SDK (payments.getCatalog()).
- Межстраничная реклама имеет кулдаун 3 минуты и показывается только в логических паузах.
- Покупка VIP-статуса (vip_status) или отключения рекламы (no_ads) полностью отключает межстраничную рекламу и даёт мгновенные награды за видео без роликов.

4. Жизненный цикл SDK (п. 1.19, 2.14):
- Язык определяется при старте из ysdk.environment.i18n.lang (поддерживается ?lang= для тестов).
- LoadingAPI.ready() вызывается после полной готовности к игре.
- GameplayAPI.start() и GameplayAPI.stop() вызываются при старте и вокруг рекламы.
- Подключена обработка событий ysdk.on('game_api_pause') и 'game_api_resume'.

5. Адаптивность (п. 1.10):
- Поддержка экранов от 360px до 4K, системный скролл и swipe-to-refresh заблокированы. Управление в один клик/тап одной рукой.

Спасибо за проверку!
```
